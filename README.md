# Simple Interest Calculator

## Description
This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: The initial amount.
- Rate: Annual rate of interest.
- Time: Duration in years.

## Output
- Simple Interest
- Total Amount (Principal + Simple Interest)
